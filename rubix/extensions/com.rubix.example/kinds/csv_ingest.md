# `com.rubix.example.csv_ingest`

Ingest a batch of CSV-shaped rows into one of the extension's owned
warehouse tables.

The extension declares two tables via `contributes.warehouse_tables[]`:

| dataset     | table (after host prefix)              | source schema (datablist)              |
|-------------|----------------------------------------|----------------------------------------|
| `customers` | `com_rubix_example__customers`         | Customers CSV (Customer Id, First Name, …, Country, …) |
| `products`  | `com_rubix_example__products`          | Products CSV (Internal ID, Name, …, Price, Stock, Availability) |

Wire shape:

```json
{ "dataset": "customers",
  "rows": [ { "customer_id": "DD37…", "first_name": "Sheryl",
              "country": "Chile", "email": "…", "subscription_date": "2020-08-24" } ] }
```

The host:

- Refuses calls without a tenant-scoped caller (`Error::Capability`).
- Stamps `tenant_id` onto every row before the INSERT — extensions
  cannot spoof cross-tenant writes.
- Validates the row columns against the declared
  `contributes.warehouse_tables[].columns[]` schema; unknown columns
  refuse with `Error::Validation`.

Returns the number of rows the warehouse engine acknowledged.

A bundled `data/` directory ships small samples
(`customers-sample.csv`, `products-sample.csv`) generated by
[datablist/sample-csv-files](https://github.com/datablist/sample-csv-files)
so a fresh install can demo end-to-end without external downloads.
