### Drift to watch for

- **Phasing markers in code comments** ("Phase 2a", "lands in Phase 4"). The lint script catches doc-tier refs but **not** phasing prose.
- **`.rs` files appearing next to a sibling `foo/` directory.** Rust refuses to compile (E0761).
- **Heavy upstream features pulled in transitively.** Prefer `[dev-dependencies]` over `[dependencies]` for test-only needs.

### Lessons from prior passes (don't relearn these)

- **Recorded-LLM tests** — use the upstream `starter_ai::testing::RecordingAiRunner` + `ScriptTurn`. Don't roll a new fake.
- **ai-agent propagator** — only routes **declared trigger slots** into a body's input map. Tool dispatch falls back to name resolution against the host registry per `compute_visible_tools`.
- **Tool id vs module path** — external tool ids ride under `rubix.<area>.<verb>`; module paths stay descriptive.
- **Postgres error matching** — SQLSTATE codes (`23514`, `23505`) are stable; matching on message text is not.
- **`default-run` matters.** Without it, `cargo run -p rubix-agent` becomes ambiguous as soon as a second `[[bin]]` lands.
