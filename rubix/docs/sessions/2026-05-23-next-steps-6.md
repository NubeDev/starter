### Why PR 3 is blocked

Scoping PR 3 surfaced three gaps that cannot be worked around in
rubix without forking upstream contracts or shipping a hack:

- **U1.** `starter-mcp::http::handle()` has no task-local for
  session locale; tools dispatched via MCP cannot read
  `Accept-Language`. Required for PR 3's exit signal ("Spanish
  output on `Accept-Language: es-AR`").
- **U2.** `InMemoryTransport { _private: () }` is a stub.
  THIN-SLICE PR 3 calls for "round-trip via the MCP testing
  harness"; bypassing the transport in rubix's test would not
  exercise framing or the `initialize` handshake — a hack.
- **U3.** `FlowAsTool` has no `from_registry` constructor and
  `FlowRegistry` has no `resolve(flow_id, revision)`. Wrapping
  `com.rubix.scheduled-system-check` today means ~50 lines of
  hand-rolled per-flow glue, which R2 explicitly forbids.
