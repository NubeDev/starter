# docs/testing/

**Tier:** Testing walkthroughs and ops runbooks for QA.

Different from `docs/design/tests/` (which describes the testing
**rules** — R10, the two-layer convention, the recorded-LLM
harness). This folder holds the *narrative* walkthroughs:

- "How to reproduce the Phase 1 system-check smoke test by hand."
- "How to populate fixture data for the user-admin integration suite."

Walkthroughs may reference `docs/design/tests/` but should not
contain rules themselves.
