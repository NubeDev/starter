## Built-ins (`$__dashboard`/`$__user`/`$__from`/`$__to`)

Excluded from the *variable dependency graph* by design (the `__` prefix is filtered in
`referencedVariables`): they are resolved by the server binder / time layer, not by another
dashboard variable, so they create no cascade edge. They flow through the existing
`QueryRequest` (time range already wired by WS-01); no extra UI is required for them.
