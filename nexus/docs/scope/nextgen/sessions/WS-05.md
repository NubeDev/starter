## Scope executed this session (complete, correct, green slices)

The spec is large (folders + rows + repeat + JSON model + versioning + 4 sharing
modes). Per HOW-TO-CODE / the unattended rules, this session ships the
**self-contained, fully-correct** slices end-to-end rather than half-landing the
security-heavy or canvas-coupled ones:

1. **Folders** — full vertical: migration (`0602_folders.sql`), nestable
   tenant-scoped RLS table + store (incl. `insert_with_id` for the undo path),
   DTOs, CRUD routes with C6 recording, folder `Reversible`, and the UI data
   layer (`api/folders/*`, `useFolders`, `useFolderMutations`).
2. **`folder_id` + `starred` on dashboards** — migration (`0603_dashboard_folder_star.sql`),
   store/record/DTO/route plumbing; carried on `UpdateDashboardRequest`
   (`folder_id`/`clear_folder`/`starred`) and surfaced on the summary/detail DTOs.
3. **id-stable dashboard insert** (`insert_with_id`) — resolves the WS-12
   delete-undo follow-up so undo-of-delete / redo-of-create round-trip.
4. **Duplicate dashboard** — `POST /dashboards/:slug/duplicate` copies a
   dashboard + its panels + its variables under a fresh id and derived slug.
5. **JSON export/import** — `GET /dashboards/:slug/export` emits the C1 model
   (appearance + panels + variables); `POST /dashboards/import` validates
   `schema_version` and re-creates, dropping a panel's datasource to NULL when the
   importing tenant lacks it (C1 cross-tenant rule).
6. **C6 audit/undo wiring for the dashboard + folder kinds** — `record(...)` in
   dashboard create/update/delete and folder create/update/delete; folder
   `Reversible` (snapshot strategy) + registry + manifest entry (coverage guard
   green); the dashboard delete `Reversible` uses `insert_with_id`.
7. **UI data layer + contract** — `openapi.json` regenerated and `pnpm codegen`
   re-run; named types, folder API client + hooks, and dashboard
   export/import/duplicate hooks (`useDashboardPortability`) added. Backend
   `cargo test --workspace --lib` green; UI `typecheck`/`test`/`build` green.
