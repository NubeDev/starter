## Plan (remaining work)

1. **C2 binder (`nexus-store/src/query/bind/`)** — `bind(sql, &BindCtx) -> Result<BoundQuery, BindError>`.
   Returns `{ sql (with $N placeholders), args: Vec<SqlValue>, validated_identifiers }`. Values
   ALWAYS bound; only vetted identifiers/fragments inserted as text. Macros: `$__timeFilter(col)`,
   `$__timeGroup(col, '5m'|$__interval)`, `$__timeFrom`, `$__timeTo`, `$__interval`, `$var`,
   `${var}`, `${var:csv}`, `${var:singlequote}`, `$__sqlIn(var)`, kind `$param` (bound), host
   tokens `$caller_tenant_id`/`$caller_user_id` (rejected if caller-supplied). Versioned `BindCtx`
   per C2: v1 time+vars live; `params`+`host_tokens` reserved and implemented here. `Dialect` trait
   + Postgres dialect for the time-bucket seam (WS-08).

3. **Wire into query path** — extend `QueryRequest` (DTO) with `time_range` + `variables`; build a
   `BindCtx` from the request + `Principal` host tokens; bind then run.
4. **Query history (D)** — migration `0801_query_history.sql` (RLS), store module, DTO,
   `GET /api/v1/query-history`, record-on-run, history drawer in Explore.
