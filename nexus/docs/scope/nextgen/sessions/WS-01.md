## Assumptions

- `$__interval` is computed client-side from `(to-from)/targetDataPoints` with a fixed default
  target (the spec allows either side; client-side keeps WS-01 self-contained and the binder already
  accepts `interval_secs`).
- The spec's "server-authoritative now" is for multi-panel skew; we freeze one `now` per refresh
  tick *client-side* and send absolute instants, so every panel in a refresh shares the same frozen
  instant (acceptance criterion met) without a new endpoint. Recorded as a deviation, not a hack.
- Zoom-by-drag (scope item 6) and per-panel override (item 7, explicitly "stretch") are deferred —
  see Follow-ups.
