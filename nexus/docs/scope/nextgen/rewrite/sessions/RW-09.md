## Design (lane-respecting)

RW-09 owns `source/{http_ingest,zenoh}.rs`, one thin ingest route, the
datasource-kind manifest entry, and a BACKPRESSURE.md append.

- **http_ingest** cannot be built by `native_registry` (it needs the flow id and a
  channel handle). `FlowManager` carries a shared `IngestChannels`
  (`Arc<Mutex<HashMap<flow_id, mpsc::Sender>>>`); the per-flow metered registry
  binds the `http_ingest` builder with the flow id + channel injected
  (`flow/metered/registry.rs::bind_http_ingest`). On `start` the source registers
  its bounded receiver; `Drop` unregisters. The route reaches the senders via
  `state.flows.ingest()` and does a **non-blocking** `try_push` — Full →
  `429 + Retry-After`, no silent drop. Tenant scoping: the domain resolves the
  flow scoped to the caller's tenant first, so unknown / not-running / cross-tenant
  all collapse to `404` (no existence leak).
- **zenoh** is feature-gated OFF (`nexus-engine` `zenoh` feature → `dep:zenoh`).
  Registered in `native_registry` + `registry/descriptor.rs` only under the gate so
  the palette never offers a node the registry cannot build. `Source::commit` is a
  no-op (at-most-once v1). Cancellation is handled by the pipeline's `drive_source`
  (races `read()` against `token.cancelled()`), so the source holds no token; the
  session drops on cancel, closing the subscription.

## Assumptions / deviations

- **Shared `ingest.write` path built here, not reused.** The spec said to share
  RW-07's `ingest.write`; that work is deferred (RW-07b). RW-09 built the bounded
  push channel in the engine source so RW-07b routes through `IngestChannels::
  try_push` rather than inventing a second path. Logged as a follow-up.
- **Zenoh store-side connect probe not implemented.** The manifest entry is a pure
  catalogue addition (like `mqtt`, which also has no `test_connection` enum arm).
  A store-side connect/probe for zenoh is RW-04's `DatasourceKind` lane — logged as
  a follow-up.
- **Default build carries zero zenoh deps** — `cargo tree -p nexus-engine` greps 0
  occurrences of `zenoh`; `--features zenoh` greps 81. Heavy dep gated per §8.
