## Outcome

Added `nexus-engine/src/core/` (additive, zero ArkFlow imports):
- `error.rs` — `EngineError` (Build/Source/Processor/Sink) + `EngineResult`.
- `node.rs` — `Source::read`/`Processor::process`/`Sink::write`+`close` async traits
  over `datafusion::arrow::array::RecordBatch`, matching roadmap §6 verbatim.
- `registry.rs` — instance `Registry` of name→builder maps, last-wins, no global state.
- `config.rs` — `PipelineConfig::from_value` parsing the existing
  `{input, pipeline:{processors, buffer_capacity?}, output}` shape; default capacity 64.
- `outcome.rs` — `RunOutcome { Completed, Cancelled }`.
- `pipeline.rs` — `Pipeline::build` + `run(token)`: source task → bounded mpsc →
  processor chain → sink; biased `select!` on cancel; sink closed exactly once on
  every terminal path; backpressure via the channel bound.
- `mod.rs` barrel; `pub mod core;` appended to `lib.rs` (🔶 shared, append-only).

Tests: `tests/core/pipeline_test.rs` (registered as `[[test]]` `core_pipeline`) — 5
scenarios: finite completion + ordering + single close; cancellation drains and closes
once; bounded channel stalls a fast source against a gated sink; registry rejects
unknown type with a useful message; source error propagates while the sink still closes.

`cargo test -p nexus-engine` green (all suites); `cargo clippy -p nexus-engine
--all-targets` clean. No DTOs touched → no openapi/codegen.
